# Controle de Alunos em Java

Projeto acadêmico desenvolvido em Java com o objetivo de praticar conceitos fundamentais da Programação Orientada a Objetos (POO), como classes, atributos, métodos e encapsulamento.

## 📌 Funcionalidades
- Cadastro de alunos
- Exibição dos alunos cadastrados
- Verificação da situação do aluno (Aprovado ou Reprovado) com base na nota

## 🛠️ Tecnologias utilizadas
- Java
- Programação Orientada a Objetos

## ▶️ Como executar o projeto
1. Compile os arquivos Java:
   javac src/*.java

2. Execute o programa:
   java -cp src Main

## 🎓 Contexto acadêmico
Projeto desenvolvido como exercício da faculdade no curso de Sistemas de Informação.
