# Controle de Alunos em Java

Projeto desenvolvido como exercício acadêmico para praticar conceitos de
Programação Orientada a Objetos em Java.

## Funcionalidades
- Cadastro de alunos via console
- Armazenamento de nome, RA e nota
- Listagem de alunos
- Verificacao de aprovacao ou reprovação

## Tecnologias
- Java
- Programação Orientada a Objetos (POO)
- Console

Projeto com fins educacionais.
